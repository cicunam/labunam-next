# Guía del equipo de LabUNAM

Esta guía parte de que sabes HTML, CSS y JavaScript, pero todavía no conoces Next.js.
Los ejemplos corresponden a este repositorio: Next con App Router, React y TypeScript.
No necesitas aprender todo el framework antes de trabajar en un componente.

## Orden de lectura

1. [Preparar el entorno](01-primeros-pasos.md): instalar, arrancar y resolver problemas comunes.
2. [Cómo está dividido y cómo funciona](02-arquitectura.md): conceptos de Next y recorrido de una petición.
3. [Crear un componente](03-componentes.md): carpeta, props, estilos e interacción.
4. [Consultar la base de datos](04-base-de-datos.md): reutilizar el catálogo y ampliar consultas.
5. [Crear y ejecutar pruebas](05-pruebas.md): Vitest y Playwright con ejemplos.
6. [Trabajar con Storybook](06-storybook.md): desarrollar estados visuales sin MySQL.
7. [Imágenes y entrega de cambios](07-imagenes-y-entrega.md): fotos, logos, revisión y validación.

Si sólo vas a cambiar estilos, empieza con 1, 3 y 6. Si vas a cambiar búsqueda o
filtros, lee también 2, 4 y 5. Los fragmentos de ejemplo son didácticos: no crean
archivos ni rutas automáticamente. Los comandos se ejecutan desde la raíz de
`labunam-next`, salvo que se indique otra cosa.
